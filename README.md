# Serenvo · Espace Privilégié

Site externe Serenvo hébergeant le formulaire d'inscription Cliente Signature et le simulateur de demande personnalisée.

## Structure

- `index.html` — Page d'accueil avec choix entre Inscription et Demande
- `inscription.html` — Formulaire pour devenir Cliente Signature (8 étapes + signature)
- `demande.html` — Simulateur de demande d'article personnalisé (12 étapes)
- `vercel.json` — Configuration des URLs propres

## URLs publiques

- `/` — Page d'accueil
- `/inscription` — Formulaire Cliente Signature
- `/demande` — Simulateur de demande
